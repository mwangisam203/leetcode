ARRAYS: BUILD THE INVARIANT BEFORE THE LOOP

Python lists grow dynamically. Pass ten values and len(nums) is ten; it is not a
capacity setting. For indices, use 0 through len(nums)-1. range(len(nums)) visits
exactly those indices. range(len(nums), 0, -1) visits n, n-1, ..., 1: those are
valid FREQUENCIES, but n is not an index into a list of length n.

1. INPUT CONTRACTS

Before choosing a pattern, ask:
- Is the input sorted? Are duplicates and negative values allowed?
- Do I return values, indices, a count, or a modified prefix length?
- May I mutate the input? What should empty input do?

The examples intentionally have different contracts:
- minVal / findMin / largest: empty input raises ValueError.
- Notes.py minimum helpers: empty input returns None.
- max_subarray_sum: nonempty input; all-negative input returns its largest value.
- max_stock_profit: empty or falling input returns 0 (choose no trade).
- two_sum_sorted: sorted input, zero-based indices, [] if absent.

2. TWO POINTERS: USE ORDER TO RULE OUT WORK

For sorted Two Sum [1, 2, 4, 7], target 6:
left=0, right=3: 1+7=8 -> decrease right (moving left cannot reduce the sum).
left=0, right=2: 1+4=5 -> increase left (moving right cannot increase the sum).
left=1, right=2: 2+4=6 -> return [1, 2].
Invariant: if a valid pair remains, it lies between the two pointers.
Use left < right so an element cannot pair with itself.

Sorted Squares also uses both ends: the largest absolute value can be at either
end, so write the largest square into the last free output position.
Sorting an unsorted list changes positions; do not sort Two Sum input when the
answer must use its original indices unless you retain those indices.

3. PREFIX SUMS: DEFINE THE BOUNDARY

nums   = [2, -1, 4]
prefix = [0,  2, 1, 5]
prefix[i] = sum of nums[:i], excluding nums[i].
Sum of [start, stop) = prefix[stop] - prefix[start].
For [1, 3): 5 - 2 = 3, matching -1 + 4.
The initial zero makes ranges starting at index 0 use the same formula.
An empty range [i, i) has sum zero. Negative numbers are fine.

Product Except Self uses a related invariant: before processing i, prefix is
the product strictly BEFORE i. Write it first, then include nums[i]. The reverse
pass multiplies by the product strictly AFTER i. No division is needed, so zeros
are supported. For [0, 2, 3], the answer is [6, 0, 0].

4. MUTATION, ALIASES, AND RETURN VALUES

alias = nums refers to the same list; copy = nums.copy() creates a shallow copy.
move_zeroes and rotate_right change nums and return None:
    values = [0, 1, 0, 3]
    move_zeroes(values)
    # values is [1, 3, 0, 0]
Do not write values = move_zeroes(values); that replaces values with None.

compact_sorted returns a length, not a new list:
    values = [1, 1, 2, 2, 3]
    length = compact_sorted(values)
    # values[:length] is [1, 2, 3]; the suffix is unspecified.
Its write pointer bounds a prefix of distinct values already processed.

rotate_right normalizes k with k %= len(nums); test empty input first to avoid
modulo by zero. A negative k rotates left. merge_sorted returns a new list and
keeps both inputs unchanged. Python list.sort() mutates and returns None;
sorted() returns a new list. Both may need O(n) sorting workspace.

5. WINDOW OR PREFIX LOOKUP?

A fixed-size sum window subtracts the outgoing value and adds the incoming one;
negative values are fine because the size determines when to move the left edge.
A variable-size sum window needs a reason that shrinking always helps. Negative
values can break that reason: [1, -1, 5] contains a sum-5 interval that shrinking
based only on the running sum can overlook. For counting exact sums with negative
numbers, study subarray_sum in Hashing/hashing.py instead.

6. TRACE AND CHECK

Track columns such as index | current value | left | right | result.
Predict the return value before running. Compare with a small reference answer.
Include [], [5], all equal, all negative, already sorted, and duplicates.
For mutation problems, compare the final list as well as the return value.
Do not assume every nested loop is quadratic: count total pointer movements.
